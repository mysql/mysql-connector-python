Requirements
============

* MySQL 8.0.0 or higher, with the X Plugin enabled
* Python >= 3.10
* Protobuf C++ (version == 5.29.4)
* Python Protobuf (version == 5.29.4)
* dnspython (version == 2.8.0) for DNS SRV support
* lz4 (version == 4.4.4) for connection compression support
* zstandard (version >= 0.12.0, <= 0.25.0) for connection compression support
